# 📊 Student Result Analysis Dashboard

This project is a **Power BI Dashboard** that analyzes and visualizes student academic performance. It provides interactive insights into students' marks, overall results, and subject-wise performance.

## 🚀 Features
- Student marks analysis
- Subject-wise performance
- Overall result summary
- Interactive filters and visuals
- Pass/Fail analysis

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV Dataset
